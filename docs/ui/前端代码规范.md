# PNN Garden 前端代码规范

> **适用范围**：`pnn_garden` 桌面端前端  
> **技术栈**：React · Next.js · Electron · Tailwind CSS · Framer Motion · Live2D  
> **视觉基准**：见同目录 [`风格.md`](./风格.md)（Obsidian Glass / Bento Grid 设计体系）

本文档为**强制性开发规范**。新增或修改前端代码时，必须遵循本文档；视觉样式以 `风格.md` 为准，工程实现以本文档为准。

---

## 1. 技术栈与职责边界

| 层级 | 技术 | 职责 |
|------|------|------|
| UI 框架 | **React 18+** | 组件化 UI、状态与交互 |
| 路由与渲染 | **Next.js 14+（App Router）** | 页面路由、SSR/SSG、API Routes |
| 桌面壳 | **Electron** | 窗口管理、系统 API、本地资源访问 |
| 样式 | **Tailwind CSS 3+** | 原子化样式、设计 Token |
| 动效 | **Framer Motion** | 入场、过渡、手势、布局动画 |
| 角色演出 | **Live2D（Cubism SDK / pixi-live2d-display）** | 立绘渲染、表情与动作 |
| 语言 | **TypeScript 5+（strict）** | 全项目类型安全 |

### 1.1 禁止事项

- 禁止引入第二套 CSS 方案（如 styled-components、CSS Modules 与 Tailwind 混写业务样式）。
- 禁止在 Renderer 进程直接 `require('fs')` 等 Node API；必须通过 **Preload + contextBridge** 暴露。
- 禁止在组件内硬编码颜色/间距魔法数；必须使用 Tailwind 扩展 Token 或 `风格.md` 已定义的值。
- 禁止在 Live2D Canvas 层使用 DOM 覆盖实现复杂交互（应通过统一输入桥接层）。

## 3. TypeScript 规范

### 3.1 编译选项

`tsconfig.json` 必须开启：

```json
{
  "compilerOptions": {
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "noImplicitOverride": true,
    "verbatimModuleSyntax": true
  }
}
```

### 3.2 类型约定

```typescript
// ✅ 组件 Props 必须显式定义并导出
export interface GlassCardProps {
  children: React.ReactNode;
  className?: string;
  hoverable?: boolean;
}

// ✅ 使用 type 描述 API 响应与 IPC 载荷
export type IpcChannel = 'asr:start' | 'asr:stop' | 'window:minimize';

export interface AsrPartialPayload {
  text: string;
  isFinal: boolean;
}

// ❌ 禁止滥用 any
// ❌ 禁止 @ts-ignore（除非附注原因且经 review）
```

### 3.3 枚举与常量

- 有限状态集用 **字符串字面量联合类型**，不用 `enum`。
- 魔法字符串收入 `lib/constants.ts` 或 `types/`。

```typescript
export const APP_CHANNELS = {
  ASR_PARTIAL: 'asr:partial',
  ASR_FINAL: 'asr:final',
} as const;

export type AppChannel = (typeof APP_CHANNELS)[keyof typeof APP_CHANNELS];
```

## 4. React 组件规范

### 4.1 组件模板

```tsx
'use client'; // 仅在有 hooks / 浏览器 API / 动效时需要

import { cn } from '@/lib/cn';
import type { GlassCardProps } from './types';

export function GlassCard({ children, className, hoverable = true }: GlassCardProps) {
  return (
    <div
      data-component="glass-card"
      className={cn(
        'rounded-[40px] border border-white/10 bg-white/5 backdrop-blur-[32px]',
        'shadow-[inset_0_1px_1px_0_rgba(255,255,255,0.05)]',
        hoverable && 'transition-[border-color] duration-400 hover:border-white/25',
        className,
      )}
    >
      {children}
    </div>
  );
}
```

### 4.2 规则清单

1. **默认使用函数组件**；不使用 class 组件。
2. **一个文件一个主组件**；私有子组件可同文件但不导出。
3. **Props 解构 + 默认值**；超过 5 个 Props 考虑拆分子组件或 compound pattern。
4. **`'use client'` 最小化**：能在 Server Component 渲染的不要加 client。
5. **列表渲染必须稳定 `key`**；禁止用数组 index 作为动态列表 key。
6. **副作用集中在 `useEffect`**；清理函数必须写全（定时器、订阅、IPC 监听）。
7. **事件处理命名**：`handle` + 动作（`handleSubmit`、`handleMicToggle`）。

### 4.3 Server / Client 分工

| 场景 | 选择 |
|------|------|
| 静态布局、SEO 元数据 | Server Component |
| 动效、麦克风、Live2D、窗口 IPC | Client Component |
| 数据预取 | Server Component + `fetch` 或 Route Handler |

## 5. Next.js 规范

### 5.1 App Router

- 页面文件：`app/**/page.tsx`
- 布局文件：`app/**/layout.tsx`
- 加载态：`loading.tsx`；错误边界：`error.tsx`
- 路由分组用 `(group)`，不影响 URL

### 5.2 API Routes

```typescript
// app/api/asr/stream/route.ts
import { NextResponse } from 'next/server';

export async function POST(request: Request) {
  const body = await request.json();
  // 仅做 BFF 转发或轻量校验；重逻辑放 Electron 主进程或 Python 服务
  return NextResponse.json({ ok: true });
}
```

- API Route 只做**协议适配与校验**，不堆业务逻辑。
- 与 Electron 通信优先 **IPC**；Web 调试时可用 HTTP 代理到本地服务。

### 5.3 Electron 集成

```text
开发：Next.js dev server (localhost:3000) ← Electron BrowserWindow 加载
生产：next build && next export / standalone → Electron 加载静态或内嵌服务
```

- `next.config.ts` 需配置 `output: 'standalone'` 或 `assetPrefix` 以适配 `file://` / 本地服务。
- 所有系统能力通过 `window.electronAPI` 访问（Preload 注入）。

## 6. Electron 规范

### 6.1 安全基线（强制）

```typescript
// main/window.ts
new BrowserWindow({
  webPreferences: {
    preload: path.join(__dirname, '../preload/index.js'),
    contextIsolation: true,
    nodeIntegration: false,
    sandbox: true,
  },
});
```

```typescript
// preload/index.ts
import { contextBridge, ipcRenderer } from 'electron';

contextBridge.exposeInMainWorld('electronAPI', {
  asr: {
    start: () => ipcRenderer.invoke('asr:start'),
    stop: () => ipcRenderer.invoke('asr:stop'),
    onPartial: (cb: (payload: AsrPartialPayload) => void) => {
      const listener = (_: unknown, data: AsrPartialPayload) => cb(data);
      ipcRenderer.on('asr:partial', listener);
      return () => ipcRenderer.removeListener('asr:partial', listener);
    },
  },
});
```

### 6.2 IPC 命名

- 格式：`<域>:<动作>`，全小写  
  例：`window:minimize`、`asr:start`、`live2d:load-model`
- 请求/响应：`ipcRenderer.invoke` + `ipcMain.handle`
- 推送事件：`webContents.send` + `ipcRenderer.on`

### 6.3 类型声明

```typescript
// src/types/electron.d.ts
export interface ElectronAPI {
  asr: {
    start: () => Promise<void>;
    stop: () => Promise<void>;
    onPartial: (cb: (payload: AsrPartialPayload) => void) => () => void;
  };
}

declare global {
  interface Window {
    electronAPI: ElectronAPI;
  }
}
```

## 7. Tailwind CSS 规范

### 7.1 与视觉规范对齐

所有视觉 Token 以 [`风格.md`](./风格.md) 为准，并固化到 `tailwind.config.ts`：

```typescript
// tailwind.config.ts 扩展摘录
theme: {
  extend: {
    colors: {
      canvas: '#020617',
      orb: {
        indigo: '#4f46e5',
        purple: '#7e22ce',
        teal: '#10b981',
      },
    },
    borderRadius: {
      glass: '40px',
    },
    backdropBlur: {
      glass: '32px',
      '3xl': '64px',
    },
    letterSpacing: {
      headline: '-0.02em',
    },
    transitionDuration: {
      400: '400ms',
    },
    keyframes: {
      float: { /* 见风格.md */ },
      shimmer: { /* 见风格.md */ },
    },
    animation: {
      float: 'float 8s ease-in-out infinite',
      shimmer: 'shimmer 2.5s linear infinite',
    },
  },
},
```

### 7.2 书写规则

1. **类名顺序**（推荐）：布局 → 尺寸 → 间距 → 排版 → 颜色 → 边框 → 效果 → 动效 → 状态  
2. **合并类名**统一用 `cn()`（`clsx` + `tailwind-merge`）：

```typescript
// lib/cn.ts
import { clsx, type ClassValue } from 'clsx';
import { twMerge } from 'tailwind-merge';

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

3. **玻璃卡片**统一使用 `GlassCard` 组件，禁止复制粘贴一套玻璃样式。
4. **响应式**：桌面优先（`xl:`、`2xl:`）；主布局基准 **1920×1080**，兼顾 2K/4K。
5. **间距**：桌面模块间距默认 `gap-8`；容器圆角 `rounded-glass`（40px）。

### 7.3 全局基底

`globals.css` 必须包含：

- 背景色 `#020617`
- 3% 噪点纹理叠加层
- 三颗 ambient orb（Indigo / Purple / Teal）
- `Inter` 或 `SF Pro Display` 字体栈
- 标题 `tracking-headline`，正文 `tracking-wide`

## 8. Framer Motion 规范

### 8.1 使用场景

| 场景 | API |
|------|-----|
| 入场/退场 | `motion.div` + `initial` / `animate` / `exit` |
| 列表交错 | `variants` + `staggerChildren` |
| 布局变化 | `layout` / `LayoutGroup` |
| 手势 | `whileHover` / `whileTap` / `drag` |
| 页面切换 | `AnimatePresence` |

### 8.2 与风格.md 对齐的入场动画

```tsx
const restoreVariants = {
  hidden: { opacity: 0, scale: 1.05, filter: 'blur(24px)' },
  visible: {
    opacity: 1,
    scale: 1,
    filter: 'blur(0px)',
    transition: { duration: 0.5, ease: [0.22, 1, 0.36, 1] },
  },
};

export function BentoItem({ children }: { children: React.ReactNode }) {
  return (
    <motion.div
      variants={restoreVariants}
      initial="hidden"
      whileInView="visible"
      viewport={{ once: true, margin: '-80px' }}
    >
      {children}
    </motion.div>
  );
}
```

### 8.3 性能规则

1. 只对 `transform`、`opacity`、`filter` 做动画；避免动画 `width`/`height`/`top`/`left`。
2. Live2D Canvas 容器**不要**整体做 `filter: blur()` 动画（GPU 开销大）。
3. 全局动效加 `prefers-reduced-motion` 降级：

```tsx
const shouldReduceMotion = useReducedMotion();
```

4. 复用 `variants` 常量，放 `components/ui/motion-presets.ts`。

## 9. Live2D 规范

### 9.1 架构

```text
Live2DCanvas (Client Component)
  ├── useLive2DModel()      # 模型加载与生命周期
  ├── useLive2DMotion()     # 动作/表情切换
  └── Live2DInputBridge     # 点击命中、拖拽（与 React 事件隔离）
```

### 9.2 规则

1. Live2D 渲染在 **独立 Canvas/WebGL 层**；React 只管控件与状态，不直接操作 Cubism 内部对象。
2. 模型资源放 `public/live2d/<model-id>/`，路径通过配置加载，禁止硬编码绝对路径。
3. 模型加载必须显示 **loading / error** 状态；失败可降级为静态立绘。
4. 动作切换通过统一 API：

```typescript
export interface Live2DController {
  loadModel: (modelId: string) => Promise<void>;
  playMotion: (group: string, index: number) => void;
  setExpression: (name: string) => void;
  destroy: () => void;
}
```

5. 组件卸载时**必须**调用 `destroy()` 释放 WebGL 上下文与纹理。
6. 与 TTS/对话联动：由 `features/chat` 发事件，Live2D 层订阅；禁止双向强耦合。

### 9.3 性能

- 单场景单模型为主；多模型需评估显存。
- `requestAnimationFrame` 循环在可见时才运行（`document.visibilityState` / Intersection Observer）。
- 窗口缩放使用 `devicePixelRatio` 适配，避免模糊或过度渲染。

## 10. 状态管理

| 范围 | 方案 |
|------|------|
| 组件内 UI 状态 | `useState` / `useReducer` |
| 跨组件轻量共享 | React Context（主题、语言） |
| 全局业务状态 | **Zustand**（聊天、角色、ASR 状态） |
| 服务端数据 | TanStack Query（可选） |

```typescript
// stores/chat-store.ts
import { create } from 'zustand';

interface ChatState {
  messages: Message[];
  appendMessage: (msg: Message) => void;
  clear: () => void;
}

export const useChatStore = create<ChatState>((set) => ({
  messages: [],
  appendMessage: (msg) => set((s) => ({ messages: [...s.messages, msg] })),
  clear: () => set({ messages: [] }),
}));
```

- 禁止滥用 Context 传递高频更新数据（如 ASR partial 文本流）。

## 12. 无障碍与国际化

1. 交互元素必须有可访问名称（`aria-label` 或可见文本）。
2. 自定义按钮使用 `<button>`，不用 `<div onClick>`。
3. 动效遵循 `prefers-reduced-motion`。
4. 文案使用 i18n 键，禁止在组件内散落中英硬编码（开发调试除外）：

```typescript
const t = useTranslations('chat');
return <span>{t('input.placeholder')}</span>;
```

## 13. 性能与桌面体验

1. **代码分割**：Live2D、重型编辑器动态 `import()`。
2. **图片**：Next.js `Image` 或静态 WebP；Live2D 贴图除外。
3. **长列表**：虚拟滚动（`@tanstack/react-virtual`）。
4. **IPC 高频事件**（ASR partial）：主进程做节流（≥ 100ms）再推送。
5. **惯性滚动**：在根布局容器实现 smooth scroll + 阻尼，符合 `风格.md` Phase 5。
