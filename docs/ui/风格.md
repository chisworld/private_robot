# Web UI 设计规范（Obsidian Glass）

> 仓库：<https://github.com/chisworld/private_robot>  
> 适用范围：`apps/web/` 语音对话、ASR、TTS 页面。桌宠原生 UI 见 `pnn/pet/settings_styles.py`。

---

Phase 1: Global Atmospheric Foundation (The DNA)
Objective: Establish the environmental lighting and textural depth that prevents the dark mode from looking "flat."

Instruction:

"Define the global CSS and background architecture for a desktop web environment.

Base Canvas: Use #020617 (Deep Obsidian Black) as the primary background.

Textural Layer: Apply a global overlay of a 3% opacity Static Noise Texture. This is critical to eliminate 'color banding' on large desktop monitors and provide a high-end, cinematic film-grain feel.

Atmospheric Luminescence: Strategically place 3 massive, ultra-blurred (blur-[180px]) ambient light orbs:

Orb A (Indigo #4f46e5): Fixed at Top-Left, 20% opacity.

Orb B (Phantom Purple #7e22ce): Fixed at Mid-Right, 15% opacity.

Orb C (Aurora Teal #10b981): Fixed at Bottom-Left, 10% opacity.

Motion: These orbs must have a subtle, non-linear floating animation (animate-float) to simulate a living digital nebula.

Typography: Implement Inter or SF Pro Display. Headlines must use tracking-[-0.02em] for a condensed, premium look, while body text uses tracking-wide for readability."

Phase 2: Structural Philosophy (The Layout)
Objective: Utilize horizontal screen real estate through the "Bento Grid" methodology.

Instruction:

"Design a modular, non-linear layout system optimized for 1920x1080 and 2K/4K displays.

Desktop Bento Grid: Use a 12-column Tailwind grid system. Content modules should be encapsulated in varied-size glass containers rather than traditional lists.

Spatial Awareness: Use a consistent gap-8 for desktop spacing. Avoid clutter by implementing extreme whitespace (Apple-style margins).

Container Standards: Every module must use an aggressive corner radius of rounded-[40px].

Z-Axis Depth: Establish three distinct layers:

Layer 0: Background nebula.

Layer 1: The 'Obsidian' frosted glass cards.

Layer 2: High-contrast text, glowing icons, and interactive CTA buttons."

Phase 3: Glassmorphism Technical Specs (The Material)
Objective: Define the exact physics of the "Glass" to ensure consistency across all components.

Instruction:

"All containers must strictly follow these Obsidian Glass specifications:

Fill: bg-white/5 (semi-transparent white) or bg-slate-900/40.

Blur: backdrop-blur-[32px] to ensure underlying colors are diffused into a soft glow.

The 'Light Edge': Apply a 1px solid border border-white/10. The top and left borders should use a slightly brighter gradient to simulate a 'rim light' hitting the glass edge.

Inner Glow: Add a subtle box-shadow: inset 0 1px 1px 0 rgba(255, 255, 255, 0.05).

Refraction: When a card is hovered, the border-white/10 should transition to a border-white/25 with a smooth 400ms duration."

Phase 4: Desktop Interactive Components (Atomic UI)
Objective: Optimize for mouse-driven interactions, emphasizing hover states and precision.

Instruction:

"1. The Floating Navbar (Desktop):

Design a detached, floating header at top-6 with a width of 90-95%.

Use backdrop-blur-3xl. The Logo should feature a metallic gradient with mix-blend-mode: screen.

Menu links must feature a 'magnetic' hover effect—when the cursor is near, the text subtly gravitates toward it.

2. High-Action Buttons:

Create a 'Shimmer' button component. It features a high-saturation gradient (from-indigo-600 to-purple-600).

Inside the button, an oblique light streak (shine) moves slowly across the background. On hover, the button scales by 1.05 and triggers a shadow-[0_0_40px_rgba(124,58,237,0.5)] glow.

3. Glass Inputs:

Background bg-slate-900/60. On focus, the border must morph from a simple line into a glowing, breathing gradient that wraps around the entire input field."

Phase 5: Motion Design & Micro-Interactions (The Life)
Objective: Use the power of a dedicated GPU (like RTX 5060) to render silky-smooth transitions.

Instruction:

"1. Entrance Sequence: Use Intersection Observer to trigger staggered entry. Components should not just 'fade in'; they must 'restore'—transitioning from blur-2xl to blur-none, scale-105 to 1.0, and opacity-0 to 100.

2. Mouse Tracking Aura: Implement a global 'Cursor Glow'. A very faint, large radial gradient follows the mouse cursor. This glow is only visible when it passes 'behind' or 'through' the Obsidian Glass cards, creating a realistic glass-refraction effect.

3. Inertia Scrolling: Implement a smooth-scroll behavior with physical damping/inertia to make the desktop experience feel 'heavy' and premium."

Phase 6: Technical Implementation (The Stack)
Objective: Provide the exact coding standards for the developer AI.

Instruction:

"Generate a production-ready Vue 3 codebase using:

Vite as the build tool.

Tailwind CSS for all styling. Extend the tailwind.config.js to include:

backdropBlur: { '3xl': '64px' }

Custom keyframes for shimmer, float, and morphing-glow.

Lucide-Vue-Next for iconography (consistent duotone stroke).

Framer Motion (Motion One for Vue) for complex state-based transitions.

Structure: Provide modular SFCs (Single File Components) for NavBar.vue, BentoGrid.vue, GlassCard.vue, and PrimaryButton.vue. Ensure the code is clean, typed with TypeScript, and heavily commented."

Execution Step for the Coder AI:
"Start by generating the tailwind.config.js and the main App.vue layout that establishes the background, the noise texture, and the ambient light orbs. Then, proceed to build the Header and a 3-column Bento Grid demonstration."
